Firebase 설정 가이드
Firebase 프로젝트 생성 및 연결 방법
1. console.firebase.google.com 접속 → 구글 계정 로그인
2. "프로젝트 만들기" → 이름 입력 (예: turtle-investment)
3. 프로젝트 생성 후 "웹 앱 추가" 클릭 (</> 아이콘)
4. 앱 닉네임 입력 → "Firebase SDK 추가" 에서 firebaseConfig 복사
5. 이 파일(index.html) 상단 YOUR_API_KEY 등을 복사한 값으로 교체
6. Firestore Database → "데이터베이스 만들기" → 테스트 모드 선택
7. 파일을 저장하고 브라우저에서 열면 Firebase 자동 연결
* GitHub Pages에 올리면 어디서든 접근 가능 (모바일 포함)
* GitHub 계정 → New repository → index.html 업로드 → Settings → Pages → Branch: main → Save
